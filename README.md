# Giaccio Properties — Static Website 

Westchester County real estate site. Astro static site, deploys free to GitHub Pages.
Replaces the broken WordPress site (Eiddo theme + 2018 plugins).

## Structure
- `data/properties.json` — single source of truth for all listings. Edit this to change any listing.
- `data/properties.csv` — spreadsheet mirror for bulk edits. Run `npm run data` to rebuild JSON from it.
- `data/photo-manifest.json` — maps each property to its image set (generated by the photo pipeline).
- `data/wp-export.json` — the 5 records salvaged from the old WordPress DB.
- `public/assets/properties/<slug>/` — web-optimized photos (WebP + JPEG + thumbs, 1.3GB → 300MB).
- `src/` — Astro pages, layout, components, styles.
- `scripts/compress-photos.sh` — re-runnable photo compressor (source stays untouched).
- `scripts/csv-to-json.js` — rebuild properties.json from the CSV.

## Develop
```
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

## Editing listings (no code)
Edit `data/properties.json` (or `data/properties.csv` then `npm run data`), then `npm run build`.
`needs_data: true` marks a listing still missing beds/baths/price.

## Deploy to GitHub Pages
1. Create a repo, push this directory.
2. For a project page set `base: '/repo-name/'` in `astro.config.mjs`; for a user/org page leave `base: '/'`.
3. Add the GitHub Pages Actions workflow (withastro/action) or push `dist/` to the `gh-pages` branch.
4. Set the Formspree endpoint in `src/pages/contact.astro` (replace `FORM_ID`).
